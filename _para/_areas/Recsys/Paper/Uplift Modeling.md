# Uplift Modeling
> Estimate the incremental impact of a treatment on the outcomes

3 Main approaches
1. 2 model approach. Train 2 models on treated data and controlled data respectively, and uses the difference between two predictions to calculate Uplift value.
2. Class Transformation: Builds connection between treated group and the controlled group based on some assumptions
3. Direct estimation: Designs a model to directly estimate uplift value
