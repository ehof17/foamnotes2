# Pulsar IO

Handles the sourcing of data from an external source into pulsar
Dumping system from pulsar into databases

- Ecosystem of connectors

 
Sources - In to pulsar
- Messaging system, databases, apis

Sinks - from pulsar
- databases

Full flow
We have a file, pulsarIO source connector ingests that data into topic
Then other pulsar functions can provide other Processing
Then the sink runs and exports to databases
