# SNS
Simple Pub/Sub. Fans out one event to many consumers at once. Often times works with [[Simple Queue Service]] but doesn't have to

Like someone places an order place topic. Kitchen then reads the topic to start making the food. Payment service that validates the order. Tax service handles the taxes for the order
