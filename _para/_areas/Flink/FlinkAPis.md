# Flink APIs

### DataStreamAPI
> Low level, flexible API for building event driven applications with custom transformations
- When to Use
  - Fine grained control, custom logic, stateful operations

### Table and SQL API
> Declarative API that lets you query streams and batch data using SQL like syntax
- When to Use
  - You have SQL background; analytics pipelines; prototyping

### Complex Event processing
> Library build on DataStreamAPI for detecting complex event patterns (Sequences/anomalies)
- When to Use
  - Fraud detection, sessionization, monitoring patterns
