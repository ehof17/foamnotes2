
# How to check if compressor getting voltage

- Disengage clutch eletrical connection
- Multimneter set to 20 dc volts

- Red clip to positive battery terminal
- Check battery voltage by touching the probe
- Now one of the eletrical connection ports should match the battery's volts

Now do the same thing with the compressor electrical compressor
- Only check black and white (Should be same battery voltage)

- Check green wire
- 1 probe to black, one probe to green
- Second person has to turn car on. As soon as you turn on ac, multimeter should get a reading
- 1 probe to white, one to green

If you aren't getting voltage, could be faulty wiring or corrosion, or a different ac component
